# Modelo de pergunta

Travou por mais de 30 minutos? Copie o modelo abaixo, preencha e mande a pergunta.

Muitas vezes, só de preencher, você mesmo encontra a resposta.

```
Onde estou: (vídeo e minuto, ex.: M00 · V04, minuto 3:20)
Meu ambiente: (sistema e versão, ex.: Ubuntu no WSL, Go 1.23)

O que eu estava tentando fazer:


O que eu fiz (comando ou trecho de código):


O que aconteceu (mensagem de erro exata, copiada como texto):


O que eu esperava que acontecesse:


O que eu já tentei:

```

## Exemplo

**Pergunta que não dá para responder:**

> Meu Go não funciona. Alguém ajuda?

**Pergunta que resolve na primeira resposta:**

```
Onde estou: M00 · V04, minuto 3:20
Meu ambiente: Ubuntu no WSL

O que eu estava tentando fazer:
Conferir se o Go foi instalado.

O que eu fiz:
go version

O que aconteceu:
go: command not found

O que eu esperava que acontecesse:
Ver a versão do Go instalada.

O que eu já tentei:
Instalei pelo site oficial e fechei e abri o terminal de novo.
```

## Dicas

- Copie o erro como **texto**, não como foto da tela. Texto dá para pesquisar e copiar.
- Mande o **erro inteiro**, não só a última linha.
- Se for código, mande só o trecho que importa, entre três crases (```).
- Quando resolver, conte o que funcionou. Ajuda quem tiver o mesmo problema depois.
